# Cursor Rules Documentation

This folder contains detailed documentation for the Cursor IDE rules and project guidelines.

## Files

- **[code-style.md](./code-style.md)**: Naming conventions, formatting rules, and code organization guidelines
- **[architecture.md](./architecture.md)**: System architecture, design patterns, and component structure
- **[testing.md](./testing.md)**: Testing philosophy, unit/integration/E2E testing guidelines
- **[security.md](./security.md)**: Security best practices, authentication, data protection, and compliance

## Usage

These documents provide detailed guidelines that complement the `.cursorrules` file in the project root. They offer:

- **Detailed explanations** of coding standards
- **Examples** of best practices
- **Anti-patterns** to avoid
- **Specific guidelines** for different aspects of development

## Contributing

When updating these guidelines:
1. Keep them aligned with the main `.cursorrules` file
2. Provide clear examples
3. Update related documents if changes affect multiple areas
4. Review with the team before major changes
